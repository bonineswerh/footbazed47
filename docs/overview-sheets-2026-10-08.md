# Обзор, панели и ожидаемое качество игры

## Решения

- Матчи в обзоре: две команды с эмблемами одинакового размера, настоящий счёт между ними. Турнир и дата ниже; средняя оценка болельщиков остаётся отдельной величиной. На телефоне оценка и размер выборки переходят ниже табло. Неизвестный счёт не становится 0:0.
- Клубы: мягкая палитра из контролируемого реестра `FBZDomain.clubPalette`, включая второй цвет. Неизвестный клуб нейтрален. Provider IDs, медиа и агрегаты не меняются, новых запросов для оформления нет.
- Календарь: отдельный диалог с месяцем, сеткой с понедельника, выбранной датой, ручным вводом, «Сегодня» и «Все даты». Просмотр месяцев не загружает матчи. Выбор даты сохраняет другие фильтры и местные границы дня; диапазон 1000–9999, переходы DST прежние.
- Клавиатура: стрелки перемещают по дням, Home/End — по неделе, PageUp/PageDown — по месяцам с ограничением последнего дня. Escape закрывает с возвратом фокуса. Route/session закрывает календарь через общий overlay.
- Фильтры обзора и дневника, календарь и профиль используют одинаковую визуальную структуру: спокойный акцент в заголовке, отделённые поля, скругления, прокрутка тела, доступные действия и общий blur/focus trap. Профиль не прокручивается вместе с кнопками сохранения.
- Ожидание означает предполагаемое качество игры. В форме 10 означает ожидание исключительной игры, 5 — средней. Среднее ожидание видно в отдельном блоке страницы матча. Сравнение ожидания и впечатления раскрывается по желанию; оно по-прежнему считает одних и тех же авторов. Личное ожидание и итоговая личная оценка сохраняются. Сравнение личной оценки со средней других болельщиков удалено из интерфейса, контракт БД сохранён.
- Шкалы матча, игрока и ожидания: 0 — только пустой черновик. Метки совпадают с центром ползунка, учитывая его диаметр 28 px; заполнение тоже заканчивается в центре. Кнопки прямого выбора визуально отделены от оси и идут двумя одинаковыми рядами. 9–10 голубые по прежнему семантическому контракту.

## Актуальные ориентиры и вывод

Проверены официальные страницы [Sofascore](https://www.sofascore.com/), [FotMob](https://www.fotmob.com/) и [Flashscore](https://www.flashscore.com/) 8 октября 2026. Sofascore отдельно выводит дату, состояние матчей и избранное; FotMob ставит фильтрацию рядом с матчами; Flashscore разделяет избранное, закреплённые лиги и команды. Вывод для FOOTBAZED: выбор даты и команд должен быть быстрым, а результат игры и субъективная оценка — ясно разделёнными. Палитры, типографика и социальный контекст остаются собственными.

## Проверка и границы

Локальные проверки используют только deterministic mock. Добавлены проверки геометрии эмблем и счёта, палитр клубов, клавиатуры и диапазона календаря, настоящих координат slider, контраста, 320/390/1440 px и увеличенного текста. Визуальные эталоны обновлены только для намеренно изменённых экранов. Новые снимки панелей допускают 1% различий для сглаживания на Windows/Linux; размеры, отсутствие наложений и доступность дополнительно проверяются явными assertions. Сервер, RLS, лимиты поставщика и production-данные не меняются. Calendar/editor/explore CSS остаются ленивыми. Общий аудит проекта ещё открыт; этот этап не означает закрытие всех прежних пунктов.

Окончательный `pnpm run check:all --workers=4` прошёл: 137 unit и 519 E2E, включая Chromium, Firefox и WebKit. `pnpm run build` собрал RU/EN и проверил 76 ссылок на ресурсы. Сверка истории Supabase: все 55 локальных миграций присутствуют в production, лишних имён нет. Новых миграций на этом этапе нет.

Первый CI обнаружил отличия растеризации текста и нативного checkbox в четырёх снимках редактора профиля: до 2% Windows/Linux. Диагностические actual/diff проверены визуально: границы, размеры, переносы и действия совпадают. Для этих четырёх снимков добавлены отдельные Linux-эталоны; допуск 1% не увеличен. Загрузка кириллического Onest дополнительно проверяется явно. Календарь использует общие эталоны, которые прошли на обеих ОС.
