# Шкалы и элементы выбора — 8 октября 2026

## Изменение поведения

Шкала матча, ожидания и игрока имеет одну строку делений: пустое значение и 1–10. Все 11 центров совпадают с положениями ползунка с учётом thumb 28 px; 5 остаётся на 50%. Второй ряд числовых кнопок удалён. Точный выбор доступен через компактный список с крупными пунктами. Сохранение по-прежнему требует целого значения 1–10 и контекста болельщика. Девятка и десятка сохраняют голубой смысловой цвет.

В обзоре счёт выровнен по середине блока эмблем и названий обеих команд. Длинное название не смещает противоположную эмблему. Название и счёт занимают разные колонки.

Общие панели `form-controls` перехватывают раскрытие одиночных select и дат, сохраняя исходные поля, значения, FormData и validation. Они загружаются только при взаимодействии, без framework и дополнительных зависимостей. Обзор, дневник, сравнение, настройки, жалобы и админка используют один механизм. Для native multiple/скрытых полей механизм не применяется.

Панель принадлежит текущему overlay: она не открывает вторую модалку и не изолирует родительский диалог. Escape сначала закрывает выбор, Tab возвращает обычную последовательность фокуса, закрытие родителя/смена маршрута или сессии отменяет выбор. Открытие происходит после завершённого клика, чтобы появившаяся под указателем панель не закрывала родительское окно при отпускании. Прокрутка и изменение размеров пересчитывают положение.

Список поддерживает стрелки, Home/End, ввод начала подписи, поиск для длинных списков и disabled-варианты. Наблюдатель ограничен одним открытым select и отключается при закрытии; каталог, пришедший позднее, появляется в том же списке. Внутренний поиск не вызывает обновление статистики. Календарь использует существующую модель местных дат, сетку понедельник–воскресенье и переходы клавишами, включая корректное 31 марта → 29 февраля. Даты можно продолжать вводить вручную.

## Референсы и границы наблюдений

Проверены публичные страницы [Sofascore](https://www.sofascore.com/), [FotMob](https://www.fotmob.com/) и [Flashscore](https://www.flashscore.com/) 8 октября. В доступном HTML Sofascore отделяет быстрые группы статуса и избранного; FotMob выделяет поиск и фильтр матчей; Flashscore выделяет закреплённые турниры и свои команды. Вывод для FOOTBAZED: постоянные короткие переключатели сохраняются на странице, а длинный выбор раскрывается по запросу. Это наблюдение о структуре страниц, не заявление о полном тестировании их мобильных приложений.

## Проверки

Проверяются геометрия всех делений и вертикальное выравнивание счёта, 320/390/1440 px, светлая и тёмная темы, увеличенный текст, контраст выбранной даты, зоны нажатия 44 px, клавиатура, отмена загрузки, повтор после сбоя CSS и отсутствие лишних RPC при поиске вариантов. Сценарии используют только локальный mock. Production-оценки и профиль для проверки не изменяются.

История БД проверена перед выпуском: 55 локальных и 55 remote миграций с совпадающими названиями. Девять исторических timestamp различаются уже в прежнем baseline; этот этап не добавляет SQL и не меняет migration history.

Остальные пункты общего продуктового аудита остаются отдельной работой. Этот этап не является заявлением о завершении всего аудита или о наличии native push.
