# Обзор и доставка уведомлений — 8 октября 2026

## Цель и референсы

Сделать обзор оценок удобнее для просмотра и переходов, а центр уведомлений устойчивее к смене сессии и сетевым ошибкам. На актуальных веб-страницах [Sofascore](https://www.sofascore.com/), [FotMob](https://www.fotmob.com/) и [Flashscore](https://www.flashscore.com/) просмотрены организация матчей, быстрые фильтры, поиск и переходы между футбольными сущностями. Нативные приложения в этом этапе не исследовались.

Вывод для FOOTBAZED: команды, результат и среднюю оценку нужно различать с первого взгляда; поиск должен соответствовать выбранному разделу, а сортировка быть доступна сразу. Это публичные впечатления болельщиков с указанием размера выборки, а не статистический рейтинг поставщика. Официальная эмблема используется из имеющегося media payload, без нового запроса к API-Football; при отсутствии изображения сохраняется честный текстовый fallback.

## Реализация

- Матчи: компактные строки с отдельными эмблемами и короткими именами обеих команд, фактическим счётом, турниром, датой и семантической средней оценкой. Мягкие клубные цвета берутся из общего реестра палитр. Отсутствующий гол не становится нулём; некорректная дата не выводится.
- Клубы и турниры: количество матчей выборки. Игроки сохраняют контекст клуба конкретного выступления и существующие пометки неподтверждённой истории. Публичный aggregate RPC и его privacy scope не меняются.
- Строки — обычные ссылки: клавиатура, контекстное меню и модифицированный клик работают. Используется существующий роутер и RU/EN prefix.
- Поиск меняет placeholder по разделу. Сортировка находится рядом с поиском; на телефоне — следующей строкой. Остальные фильтры сохраняют общий modal/sheet, URL и серверную пагинацию.
- Личный head/count запрос: 30 секунд на видимой странице, 15 секунд при открытом центре; 8 секунд до отмены зависшего запроса. В фоне запросы не выполняются. Смена аккаунта и подтверждённый результат отметки отменяют предыдущий запрос, чтобы старый ответ не перезаписал новое значение.
- Ошибка обновления истории того же фильтра сохраняет данные, прокрутку, cursor и through_id. Успешное обновление заменяет снимок и возвращает список к началу. Смена фильтра не показывает старую выдачу под новым заголовком.
- Новое значение счётчика во время загрузки не теряется: появляется кнопка обновления, недоступная до завершения запроса, затем выполняется сверка счётчика.
- Общие модальные окна временно исключают фон из взаимодействий и дерева доступности. Исходные inert/aria-hidden восстанавливаются; toast остаётся доступным для объявления результата. Поддержаны вложенные панели и фильтры с вынесенными из формы контролами.

## Проверка и ограничения

Unit-сценарии проверяют отмену, таймаут, интервалы, скрытие вкладки, смену аккаунта и запоздавший ответ после подтверждённого изменения. Браузерные сценарии проверяют ссылки RU/EN, отсутствие подмены счёта, все разделы, геометрию 320/390/1440, WCAG, доступность модальных окон, сохранение истории при ошибке и событие во время загрузки. Визуальные эталоны изменены только для обновлённых экранов обзора и фильтров. Полный Quality Gate остаётся обязательным перед публикацией.

Это обновление внутренних уведомлений сайта. Фоновый web push, браузерные разрешения, realtime и системные уведомления не добавлены. Схема БД и пользовательские данные не изменяются. Общий продуктовый аудит остаётся открытым; это завершённая часть его реализации.

Локальная проверка финальной версии: `pnpm run check:all --workers=4` — 135 unit и 493 E2E, Chromium/Firefox/WebKit; `pnpm run build` и `git diff --check` успешны. RU/EN startup JS/CSS — 510632/504502 байта при бюджете 512000; это локальное измерение на тестовых данных, не оценка реальной скорости посетителей. На production подтверждены поля счёта и количества матчей существующего aggregate RPC; 55 локальных и remote миграций совпадают по именам. В этой версии нет SQL-изменений.
