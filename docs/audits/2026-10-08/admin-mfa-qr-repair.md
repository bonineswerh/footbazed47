# Исправление подключения MFA — 9 октября 2026

Владелец получил общее сообщение об ошибке после «Подключить», до показа QR. Без чтения credentials проверены Auth logs: DELETE старого черновика и POST /factors завершились HTTP 200; новый TOTP остался unverified. Создание фактора в Auth прошло, но интерфейс не завершил его отображение.

Локальный тест с реальным bundled Supabase SDK 2.112.2 и искусственным pixel SVG воспроизвёл тот же экран: прежний предел 100000 символов отвергал корректный SVG. Секрет, QR и размер настоящего ответа владельца не считывались, поэтому точный размер production QR не заявляется измеренным. Прежние тесты использовали маленькое изображение и не обнаружили эту несовместимость.

Для image-only SVG теперь действует предел 1 MiB; поддержаны raw SDK SVG, percent-encoded и base64 data URI. Внешние URL не загружаются, SVG не вставляется в HTML. Если формат, размер или загрузка изображения не позволяют показать QR, уже созданный TOTP можно подключить по ключу вручную. Повторное создание или автоматическое удаление фактора не выполняется. Код и ключ по-прежнему очищаются при закрытии/смене аккаунта/маршрута; консоль открывается только после подтверждения Auth и серверной проверки MFA.

Добавлены проверка реального SDK с большим SVG, варианты кодирования, отказ внешнему URL/слишком большому/повреждённому SVG, ручное завершение, некорректный ответ, закрытие при задержанном enrollment, loading state и английский fallback. Реальная активация фактора остаётся действием владельца.

## Повторное подключение владельцем после публикации

1. Обновите страницу `/admin`, нажмите «Продолжить».
2. Если видите «Подключение не завершено», нажмите «Удалить черновик». Это убирает незавершённую попытку, а не аккаунт сайта. Не удаляйте рабочий аккаунт из приложения-аутентификатора.
3. Нажмите «Подключить». Оставьте открытым появившееся окно с QR и полем кода.
4. На телефоне откройте приложение-аутентификатор и добавьте аккаунт по этому QR с экрана компьютера.
5. Введите текущие шесть цифр для FOOTBAZED в поле «Код из приложения» на сайте и нажмите «Подтвердить».

Если изображение не открылось, воспользуйтесь ручным добавлением: имя FOOTBAZED, ключ из этого же окна, тип «по времени». Затем подтвердите код на сайте. Ключ и QR не пересылайте в чат. Создание фактора и ввод кода выполняет сам владелец; тестирование интерфейса не означает, что его реальное подключение завершено.
